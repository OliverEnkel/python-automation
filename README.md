# Python Automatisierung

Dieses Projekt besteht aus mehreren kleinen Python-Skripten,
die einfache Aufgaben automatisieren.

## Inhalte
- Datei-Organizer (Sortierung nach Dateityp)
- Textdatei-Auswertung (Zeilen & Wörter zählen)
- Backup-Skript (ZIP-Archiv erstellen)
- Responsive Shop-Demo im NOX-Living-Stil (`shop/`)

## Ziel
Ziel war es, grundlegende Python-Konzepte wie Schleifen,
Bedingungen, Dateiverarbeitung und Module praktisch anzuwenden.

Zusätzlich enthält das Repository jetzt eine moderne Frontend-Demo,
die eine Shop-Landingpage mit Produktkarten, Bundle-Widget und
Order-Summary zeigt.

## Ausführung
### Python-Skripte
Python 3 muss installiert sein.
Die Skripte können direkt über die Konsole gestartet werden:

```bash
python organizer.py
```

### Shop-Demo
Die Shop-Seite ist statisch und kann direkt im Browser geöffnet werden:

```bash
open shop/index.html
```

Alternativ mit einem lokalen Server:

```bash
python -m http.server
```

Dann `http://localhost:8000/shop/` aufrufen.
