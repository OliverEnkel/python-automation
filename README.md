# Python Automatisierung

Dieses Projekt besteht aus mehreren kleinen Python-Skripten,
die einfache Aufgaben automatisieren.

## Inhalte
- Datei-Organizer (Sortierung nach Dateityp)
- Textdatei-Auswertung (Zeilen & Wörter zählen)
- Backup-Skript (ZIP-Archiv erstellen)

## Ziel
Ziel war es, grundlegende Python-Konzepte wie Schleifen,
Bedingungen, Dateiverarbeitung und Module praktisch anzuwenden.

## Ausführung
Python 3 muss installiert sein.
Die Skripte können direkt über die Konsole gestartet werden:

python organizer.py
